Can Lifestyle Habits Predict CGPA Band?

Data collected from 53 students of our class via Google Form survey. We used study hours, attendance, sleep, stress, backlogs, and phone usage to predict whether a student falls in Low, Medium, or High CGPA band.

3. Model Comparison (5-Fold Stratified Cross Validation)
Results — 3 Models, Same 80/20 Train-Test Split
Model CV Accuracy (5-Fold) Test Accuracy Test F1 (Macro) Notes
✓ Random Forest (n=300) 88.3% 90.9% 0.644 Highest CV accuracy — most reliable
Logistic Regression 85.8% 90.9% 0.644 Equal test accuracy, lower CV stability
KNN (k=5) 83.6% 90.9% 0.644 Lowest CV score, sensitive to scale
All 3 models got equal test accuracy (90.9%) on our 11-student test set. We picked Random Forest as the best because it had the highest CV accuracy (88.3%) meaning it generalizes better on unseen data. The low Macro F1 is because there is only 1 Medium student in the test set so that class dragged the score down.
